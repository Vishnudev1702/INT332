## Problem Statement
Set up a CI pipeline using GitHub Actions to build and push a Docker image to Docker Hub.

## Steps Performed

- Created GitHub Actions workflow
- Configured Docker Hub login using secrets
- Built Docker image using Dockerfile
- Tagged image as username/app-ci:latest
- Pushed image to Docker Hub

## Workflow File

.github/workflows/ci-docker.yml

## Commands Used

## Output

- Docker image built successfully
- Image pushed to Docker Hub
- Workflow executed automatically

## Learnings

- CI automation using GitHub Actions
- Secure authentication using secrets
- Docker image build and push process


name: Docker CI Pipeline

on:
  push:
    branches: [ "main" ]

jobs:
  build-and-push:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout repository
        uses: actions/checkout@v4

      - name: Login to Docker Hub
        uses: docker/login-action@v3
        with:
          username: ${{ secrets.DOCKER_USERNAME }}
          password: ${{ secrets.DOCKER_PASSWORD }}

      - name: Build Docker Image
        run: docker build -t ${{ secrets.DOCKER_USERNAME }}/app-ci:latest .

      - name: Push Docker Image
        run: docker push ${{ secrets.DOCKER_USERNAME }}/app-ci:latest
