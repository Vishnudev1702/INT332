Practical #1: Github actions Workflow with docker

Step 1: mkdir  my-docker-app
              cd  my-docker-app
Step2: now add 3 files app.py , requirements.txt , dockerfile , 
              One folder  .github
Step3: add app.py
from flask import Flask
app = Flask(__name__)

@app.route('/')
def home():
    return "Hello from Docker CI/CD!"

if __name__ == "__main__":
    app.run(host='0.0.0.0', port=5000)

Step 4: add the contents in requirements.txt

               Flask

Step5: add contents in dockerfile 

  FROM python:3.9-slim
  WORKDIR /app
  COPY . .
RUN pip install -r requirements.txt
CMD ["python", "app.py"]





Step 6:  add ci-cd.yml in path C:\Users\DELL\my-docker-app\.github\workflows>
             name: CI-CD Pipeline

on:
  push:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout Code
        uses: actions/checkout@v4

      - name: Build Docker Image
        run: docker build -t my-docker-app .

      - name: List Docker Images
        run: docker images

Step 7: git add .
             Git commit -m “ message”
              Git remote orgin <url of git hub repo>
               Git push origin main


Few changes required in git hub repository 

                    Go to your GitHub repo:
	•	Settings → Secrets → Actions
